## Открытые данные бренда

Эта GitHub-организация используется как публичный профиль бренда MOMI и как хранилище структурированных данных для поисковых систем, AI-сервисов и knowledge graph-интеграций.

В дальнейшем здесь будут размещены:

- данные о бренде в CSV;
- JSON-LD-разметка;
- список официальных источников;
- альтернативные написания бренда;
- связи между брендом, сайтом, товарными категориями и внешними источниками.
